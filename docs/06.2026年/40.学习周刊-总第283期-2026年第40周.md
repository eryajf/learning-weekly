### 优秀项目

---
- 项目地址：[MarkdownReader](https://github.com/davidhoo/MarkdownReader)
- 项目说明：一个基于 SwiftUI 与 WKWebView 打造的 macOS Markdown 阅读器，支持 Mermaid、KaTeX 等丰富渲染，提供三栏布局与主题定制，专注沉浸式阅读。
  ![](https://t.eryajf.net/imgs/2026/06/1781275448984.webp)
------
- 项目地址：[cc-bar](https://github.com/nanvon/cc-bar)
- 项目说明：一个原生 macOS 菜单栏工具，实时监控 Codex 与 Claude Code 的额度、用量及花费，支持多账号与桌面悬浮窗，帮助用户高效管理 AI 编码成本。
  ![](https://t.eryajf.net/imgs/2026/06/1781275724740.webp)
------
- 项目地址：[financial-management](https://github.com/LuoDi-Nate/financial-management)
- 项目说明：一个基于 Spring Boot 的自托管家庭资产管理工具，支持多成员异步填报、真实年化收益计算与 AI 资产体检，旨在确保数据隐私与全局可视，支持 Web 及 iOS PWA 平台。
  ![](https://t.eryajf.net/imgs/2026/06/1781313018882.webp)
------
- 项目地址：[desktop-cc-gui](https://github.com/zhukunpenglinyutong/desktop-cc-gui)
- 项目说明：一个基于 Tauri 2、React 19、TypeScript 与 Rust 开发的 AI 编程桌面客户端，为命令行 AI 工具提供图形界面，让编码过程可视化、可管理，支持多平台。
  ![](https://t.eryajf.net/imgs/2026/06/1781314895486.webp)
------
- 项目地址：[Annado](https://github.com/ABeehive/Annado)
- 项目说明：一个基于 React 和 Tauri 构建的 macOS 任务管理器，直接读写 Obsidian 或普通 markdown 文件，确保数据完全归用户所有，无锁定，支持自然语言日期输入与日历集成。
  ![](https://t.eryajf.net/imgs/2026/06/1781318582079.webp)
------
- 项目地址：[Message-Push-Nest](https://github.com/engigu/Message-Push-Nest)
- 项目说明：一个基于 Go 语言开发的消息推送平台，整合邮件、钉钉、企业微信等多种通知渠道，提供统一 API 与消息模板，支持自定义推送策略。
  ![](https://raw.githubusercontent.com/engigu/resources/refs/heads/images/CPT2508101507-1460x745.gif)
------
- 项目地址：[archify](https://github.com/tt-a1i/archify)
- 项目说明：Archify 是一个基于 AI Agent 技能的架构图生成工具，能够将自然语言描述自动转换为精美的技术图表，支持暗/亮主题切换与多种格式导出，旨在降低架构沟通门槛。
  ![](https://t.eryajf.net/imgs/2026/06/1781583743945.webp)
