### 优秀项目

---
- 项目地址：[ashell](https://github.com/rust-kotlin/ashell)
- 项目说明：一个基于 GPUI 的 Rust 桌面终端，融合本地远程会话和 SFTP 文件管理，提供高性能美观的 Shell 工作区，跨平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1782630472399.webp)
------
- 项目地址：[AtlasOS](https://github.com/liaokongVFX/AtlasOS)
- 项目说明：一个基于 Electron 和 React 的本地优先无限画布开发工作台，将终端、文件、浏览器、Git、AI Agent 等开发节点整合到同一可视化画布中，旨在减少窗口切换并提升效率，支持 Windows 和 macOS 平台。
  ![](https://t.eryajf.net/imgs/2026/06/1782630824266.webp)
------
- 项目地址：[tinyauth](https://github.com/tinyauthapp/tinyauth)
- 项目说明：一个基于 Go 开发的极简 OpenID 认证与授权服务器，能够为应用提供身份认证中间件，支持 OAuth、LDAP 及多种反向代理，旨在以最小体积提供全面的认证解决方案。
  ![](https://t.eryajf.net/imgs/2026/06/1782742061675.webp)
------
- 项目地址：[BonsAI](https://github.com/ojowwalker77/BonsAI)
- 项目说明：一个基于 macOS 原生开发的思想捕捉与提示整理工具，通过卡片看板、多源连接器和设备端语义纠错，帮助用户将模糊想法高效转化为精准的 AI 提示，支持 macOS 26 及以上平台。
  ![](https://t.eryajf.net/imgs/2026/07/1782954765411.webp)
------
- 项目地址：[Yield](https://github.com/chen2he/Yield)
- 项目说明：一个基于 App Store Server Notifications V 2 的自托管订单与订阅管理仪表盘，驱动于 Cloudflare 边缘，无需 API 轮询即可实时验证、存储和可视化应用内购买事件。
  ![](https://t.eryajf.net/imgs/2026/07/1783039931819.webp)
------
- 项目地址：[Claudesk](https://github.com/StaymanHou/Claudesk)
- 项目说明：一个基于 Tauri 2 开发的 macOS 原生 Claude Code 会话管理工具，能够在单个窗口内通过胶片条和画中画同时监控多个项目的运行状态，旨在减少多项目切换的注意力负担，提升并行工作效率。
  ![](https://github.com/StaymanHou/Claudesk/raw/main/docs/demo/pip.gif)
------
- 项目地址：[tabularis](https://github.com/TabularisDB/tabularis)
- 项目说明：一个基于 Rust 与 TypeScript 构建的开源桌面 SQL 工作区，提供多数据库连接、SQL 笔记本、AI 助手和内置 MCP 服务器，支持 Windows、macOS、Linux。
  ![](https://t.eryajf.net/imgs/2026/07/1783052320903.webp)
