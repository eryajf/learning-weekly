### 优秀项目

---
- 项目地址：[ccg-gateway](https://github.com/mos1128/ccg-gateway)
- 项目说明：一款基于 Rust 与 Tauri 开发的智能 AI 模型网关桌面工具，能够统一管理 Claude Code、Codex、Gemini CLI 等 Agent 的服务商配置，实现请求转发、负载均衡与故障自动转移，旨在通过解决服务商不稳定、多项目并行等痛点来提升开发效率，支持跨平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636943730.webp)
------
- 项目地址：[md-preview](https://github.com/vorojar/md-preview)
- 项目说明：一个基于 Rust 和系统 WebView 开发的 Markdown 预览工具，能够实时渲染 .md 文件并支持数学公式与图表，旨在提供轻量级、高性能的跨平台体验，支持 macOS、Windows 和 Linux 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636962209.jpg)
------
- 项目地址：[orca](https://github.com/stablyai/orca)
- 项目说明：一个基于 AI 技术开发的下一代开发环境工具，能够并行运行多个编码代理，支持 Claude Code、Codex 等，旨在提升开发效率，支持桌面和移动平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779637019206.gif)
------
- 项目地址：[Callit](https://github.com/YangZxi/Callit)
- 项目说明：一个基于 Docker 的轻量级自建 Serverless 平台，能够通过 HTTP 触发 Python 和 Node. Js Worker，旨在提供个人自动化和轻量 API 服务，支持快速开发和热更新。
  ![](https://t.eryajf.net/imgs/2026/05/1779637087953.webp)
------
- 项目地址：[skills-hub](https://github.com/qufei1993/skills-hub)
- 项目说明：一个基于 Tauri 和 React 开发的跨平台桌面应用，能够集中管理 AI 代理技能并同步到多种编码工具的全局目录，旨在简化技能管理，支持多平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779637122028.webp)
------
- 项目地址：[multi-cli-studio](https://github.com/Austin-Patrician/multi-cli-studio)
- 项目说明：一个基于 Tauri 构建的桌面工作空间，能够无缝集成 Codex、Claude 和 Gemini 等多种 AI 编码 CLI，旨在实现跨工具编排和本地自动化，支持 Windows 与 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779637159342.webp)
------
- 项目地址：[input0](https://github.com/10xChengTu/input0)
- 项目说明：一个基于本地 AI 的 macOS 语音输入工具，能够通过快捷键录音并自动转译、优化文本，旨在提升输入效率，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779637198861.webp)
------
- 项目地址：[hermes-web-ui](https://github.com/EKKOLearnAI/hermes-web-ui)
- 项目说明：一个基于 Vue 3 和 TypeScript 构建的 Web 仪表板，用于管理 Hermes Agent 的 AI 聊天会话、平台配置和使用分析，旨在提供高效的多平台 AI 代理管理体验。
  ![](https://t.eryajf.net/imgs/2026/05/1779637227185.webp)
