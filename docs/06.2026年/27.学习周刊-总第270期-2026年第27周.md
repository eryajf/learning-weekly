- 项目说明：一个基于 Tauri 和 AI 技术开发的 Redis 桌面客户端，能够通过自然语言查询和操作 Redis 数据，旨在简化数据管理流程并提升安全性，支持跨平台使用。

- 项目地址：[browser](https://github.com/lightpanda-io/browser)
- 项目说明：Lightpanda 是一个用 Zig 语言从零构建的无头浏览器，专为 AI 代理和自动化设计，提供高性能的 JavaScript 执行和低内存占用，适用于 Web 自动化平台。
------
- 项目地址：[page-agent](https://github.com/alibaba/page-agent/blob/main/docs/README-zh.md)
- 项目说明：一个基于纯 JavaScript 开发的 Web GUI 智能代理，能够通过自然语言指令操作网页界面，旨在简化用户交互，支持主流浏览器使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779612192148.webp)
------
- 项目地址：[MeowCLI](https://github.com/nekohy/MeowCLI)
- 项目说明：一个基于 Go 语言开发的 CLI 反代服务，能够实现高性能 API 转发和智能调度，旨在优化资源利用与请求处理，支持 SQLite 和 PostgreSQL 数据库。
  ![](https://t.eryajf.net/imgs/2026/05/1779612337314.webp)
------
- 项目地址：[TablePro](https://github.com/TableProApp/TablePro)
- 项目说明：TablePro 是一个基于 Swift 开发的原生数据库客户端，专为开发者提供快速、免费开源的数据库管理体验，支持多种 SQL 和 NoSQL 数据库，无需 Electron，性能优越。
  ![](https://t.eryajf.net/imgs/2026/05/1779612383344.webp)
------
- 项目地址：[OpenCodeUI](https://github.com/lehhair/OpenCodeUI)

  ![](https://t.eryajf.net/imgs/2026/05/1779616088869.webp)

- 项目地址：[clash-for-linux-install](https://github.com/nelvko/clash-for-linux-install)
