### 优秀项目

---
- 项目地址：[Recordly](https://github.com/webadderallorg/Recordly)
- 项目说明：一个基于 Electron 和 PixiJS 开发的屏幕录制与编辑工具，能够自动添加缩放、光标平滑等效果，旨在快速创建专业演示视频，支持 macOS、Windows 和 Linux 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779981985318.webp)
------
- 项目地址：[agentbro](https://github.com/shirenchuang/agentbro)
- 项目说明：一个基于 Tauri 和 React 开发的 macOS 桌面工具，能够实时展示 AI Agent 会话状态，旨在提升编程效率，支持多种 AI Agent 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1780153251106.webp)
------
- 项目地址：[vistars](https://github.com/hustcc/vistars)
- 项目说明：这是一个基于 SVG 的数据可视化风格头像库，能够从用户名和调色板生成独特头像，支持浏览器和 Node. Js 服务器端渲染，旨在提供美观且可定制的头像生成方案。
  ![](https://t.eryajf.net/imgs/2026/05/1780154308234.webp)
------
- 项目地址：[SkylerX](https://github.com/duhbbx/SkylerX)
- 项目说明：一个基于 Electron 和 Vue 3 开发的跨平台桌面数据库管理工具，支持多种 SQL 和 NoSQL 数据库，旨在提供高效的数据库操作和 AI 辅助功能，适用于开发者和数据库管理员。
  ![](https://t.eryajf.net/imgs/2026/05/1780154359303.webp)
------
- 项目地址：[Momento](https://github.com/Seaony/Momento)
- 项目说明：一个基于 SwiftUI 开发的 macOS 图片管理工具，能够集中收纳和整理图片素材，旨在为设计师和创作者提供高效的本地素材库，支持颜色筛选和自动更新。
  ![](https://t.eryajf.net/imgs/2026/05/1780155021252.webp)
------
- 项目地址：[fluxnotes](https://github.com/chansyawn/fluxnotes)
- 项目说明：一个基于 Electron 开发的 AI 时代工作流 Markdown 编辑器，能够始终置顶作为临时上下文缓冲区，支持编辑草稿、组织上下文和捕捉灵感，旨在优化与 AI 工具的输入交互过程。
  ![](https://t.eryajf.net/imgs/2026/05/1780155073865.gif)
------
- 项目地址：[markra](https://github.com/murongg/markra)
- 项目说明：一个基于 TypeScript 和 Tauri 开发的 WYSIWYG Markdown 编辑器，集成原生 AI 功能，旨在提供本地优先、隐私安全的写作体验，支持桌面和 Web 平台。
  ![](https://t.eryajf.net/imgs/2026/05/1780155116704.webp)
