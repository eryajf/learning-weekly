### 优秀项目

---
- 项目地址：[nextclaw](https://github.com/Peiiii/nextclaw)
- 项目说明：一个基于 Node. Js 开发的 AI 助手工具，能够协调代理、技能和自动化任务，旨在提供私有、轻量级的个人助理体验，支持 Windows、macOS 和 Linux 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636382827.webp)
------
- 项目地址：[GHFS](https://github.com/indragiek/GHFS)
- 项目说明：一个基于 FSKit 开发的 macOS 虚拟文件系统工具，能够将 GitHub 仓库实时挂载为只读目录，旨在简化远程代码访问与浏览，支持在 macOS 26.4 及以上平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636428599.webp)
------
- 项目地址：[desktop-cc-gui](https://github.com/zhukunpenglinyutong/desktop-cc-gui?tab=readme-ov-file)
- 项目说明：一个基于 Tauri 开发的 VibeCoding 编辑器，支持多 AI 引擎和集成开发环境，旨在为开发者提供开源和透明的编码体验，支持跨平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636475908.webp)
------
- 项目地址：[nowen-video](https://github.com/cropflre/nowen-video)
- 项目说明：一个基于 Go 和 React 开发的轻量级家庭媒体服务器，能够自动刮削影视元数据并进行 HLS 转码播放，旨在为 NAS 用户提供自托管的影音管理方案，支持 Docker 一键部署和多平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636520192.webp)
------
- 项目地址：[link-ai](https://github.com/star7th/link-ai)
- 项目说明：一个基于 Next. Js 开发的大模型安全接入网关工具，能够实现数据脱敏和全链路审计，旨在保护 AI 调用的隐私安全，支持多种主流提供商使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636564627.webp)
---------
- 项目地址：[MacSift](https://github.com/Lcharvol/MacSift)
- 项目说明：一个基于 SwiftUI 和 Liquid Glass 开发的 macOS 透明磁盘清理工具，能够按应用分组文件并安全移动到废纸篓，旨在提供用户可控的清理体验，支持 macOS Sequoia 和 Tahoe 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636862218.webp)
------
- 项目地址：[PureMac](https://github.com/momenbasel/PureMac)
- 项目说明：一个基于 SwiftUI 开发的免费开源 macOS 清理工具，能够自动清理系统垃圾、应用卸载和缓存文件，旨在提供隐私友好的磁盘空间管理，支持 macOS 13 及以上平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636904644.webp)
