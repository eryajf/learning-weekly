### 优秀项目

---
- 项目地址：[YCode](https://github.com/melon95/YCode)
- 项目说明：一个基于 Tauri 和 React 开发的桌面编码代理工作台，能够并行运行多个 CLI AI 代理并提供统一开发环境，支持编辑器、终端和会话管理等功能
  ![](https://t.eryajf.net/imgs/2026/06/1781835306098.webp)
------
- 项目地址：[MacTools](https://github.com/ggbond268/MacTools/blob/main/README.zh-CN.md)
- 项目说明：免费开源的 macOS 原生菜单栏工具集合，基于 SwiftUI+AppKit 开发，聚合高频系统功能，提供轻量快速低打扰的体验。
  ![](https://t.eryajf.net/imgs/2026/06/1781835367855.webp)
------
- 项目地址：[LockIME](https://github.com/oomol-lab/LockIME)
- 项目说明：一个基于 SwiftUI 开发的 macOS 输入法锁定工具，能够自动恢复被切换的输入源，支持全局、按应用及按网址锁定，旨在避免误切输入法，提升打字体验，适用于 macOS 14+。
  ![](https://t.eryajf.net/imgs/2026/06/1781835429289.webp)
------
- 项目地址：[OnePagent](https://github.com/sligter/OnePagent)
- 项目说明：一个基于浏览器原生单文件实现的全能 AI 代理工作台，集成多模型对话、Python 沙箱、网络搜索与技能系统，所有数据本地存储，无需任何后端服务。
  ![](https://t.eryajf.net/imgs/2026/06/1781836212847.webp)
------
- 项目地址：[maple](https://github.com/makisuo/maple)
- 项目说明：Maple 是一个基于 OpenTelemetry 和 ClickHouse 的开源可观测性平台，支持分布式追踪、日志与指标的采集和可视化，旨在降低基础设施运维门槛，适用于云原生与本地环境。
  ![](https://t.eryajf.net/imgs/2026/06/1781836333657.webp)
------
- 项目地址：[vorssaint-utils](https://github.com/vorssaint/vorssaint-utils)
- 项目说明：一款面向 macOS 的免费开源菜单栏工具集，集成了各应用独立音量调节、系统监控、窗口切换、文件暂存等功能，旨在用一个工具替代多个付费应用，支持 Apple Silicon 与 macOS 14+。
  ![](https://t.eryajf.net/imgs/2026/06/1781836383928.webp)
------
- 项目地址：[trinity](https://github.com/Abilityai/trinity)
- 项目说明：一个基于 Docker 和 Claude Code 的自主 AI 代理基础设施，提供隔离容器内 24/7 运行、记忆与协调能力，支持自托管或云端部署，确保治理、审计与扩展性。
  ![](https://t.eryajf.net/imgs/2026/06/1781836795821.webp)
