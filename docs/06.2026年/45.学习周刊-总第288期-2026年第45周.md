### 优秀项目

---
- 项目地址：[itops-agent-platform](https://github.com/qinshihu/itops-agent-platform)
- 项目说明：基于大语言模型开发的多 Agent 运维平台，能实现告警自动诊断修复闭环，支持容器和 K8s 管理，旨在解放运维人员。
  ![](https://github.com/qinshihu/itops-agent-platform/raw/main/docs-assets/0-3.gif)
------
- 项目地址：[oxideterm](https://github.com/AnalyseDeCircuit/oxideterm)
- 项目说明：一个基于 Tauri 与 Rust 开发的 AI 原生 SSH 工作区，能够整合终端、SFTP 与端口转发，旨在以本地优先、零遥测和高安全性提升远程运维效率。
  ![](https://github.com/AnalyseDeCircuit/oxideterm/raw/main/docs/media/ai-terminal-demo.gif)
------
- 项目地址：[codux](https://github.com/duxweb/codux)
- 项目说明：一个基于 Rust 与 GPUI 开发的 AI 编码终端，能够统一管理多种 AI CLI 与远程会话，旨在提升长任务协作效率，支持桌面、手机与服务器多端使用。
  ![](https://t.eryajf.net/imgs/2026/07/1783261513685.webp)
------
- 项目地址：[CloseUp](https://github.com/oomol-lab/CloseUp)
- 项目说明：一个基于 Swift 开发的 macOS 窗口控制工具，能够在 Mission Control 中直接关闭、最小化或隐藏窗口，旨在提升多窗口管理效率，支持原生键盘操作与多语言使用。
  ![](https://t.eryajf.net/imgs/2026/07/1783298385689.webp)
------
- 项目地址：[BetterCmdTab](https://github.com/rokartur/BetterCmdTab)
- 项目说明：一个基于 Swift 开发的 macOS 应用切换增强工具，能够优化 ⌘Tab、窗口与标签管理，旨在以原生高效、零遥测体验提升多任务效率，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/07/1783383704977.webp)
------
- 项目地址：[agentsview](https://github.com/kenn-io/agentsview)
- 项目说明：一个基于 Go 与 Svelte 开发的本地优先会话分析工具，能够搜索并统计多种 AI 编码代理的会话与成本数据，旨在统一管理本机智能编程记录并提升洞察效率。
  ![](https://t.eryajf.net/imgs/2026/07/1783383942570.webp)
------
- 项目地址：[kkRepo](https://github.com/klboke/kkRepo/blob/main/README.cn.md)
- 项目说明：一个自托管制品仓库，采用 MySQL 与 OSS/S 3 存储，兼容 Nexus 迁移，支持多副本部署，旨在简化企业制品管理。
  ![](https://t.eryajf.net/imgs/2026/07/1783740158631.webp)
