### 优秀项目

---
- 项目地址：[TaskTick](https://github.com/lifedever/TaskTick)
- 项目说明：一个基于 SwiftUI 和 SwiftData 开发的 macOS 任务管理应用，能够通过菜单栏常驻实现定时任务调度、脚本执行和系统通知，旨在提供简便的 crontab 替代方案，支持 macOS 14 及以上系统使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779616293161.webp)
------
- 项目地址：[FluxMonitor](https://github.com/chentao1006/FluxMonitor)
- 项目说明：一个基于 Next. Js 开发的系统监控工具，能够实时监控 CPU、内存等资源并管理进程，旨在为 Mac 服务器提供全面的管理界面，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779616474717.webp)
------
- 项目地址：[Clawith](https://github.com/dataelement/Clawith)
- 项目说明：一个基于 FastAPI 和 React 开发的开源多智能体协作平台，能够为每个 AI 智能体提供持久身份、长期记忆和工作空间，旨在构建智能体团队协作的数字员工环境，支持多种 LLM API 和渠道集成使用。
------
- 项目地址：[DeepSeek-GUI](https://github.com/XingYu-Zhong/DeepSeek-GUI)
- 项目说明：一个基于 DeepSeek TUI 开发的桌面智能体工作台，能够集成聊天、代码管理和文件审查功能，旨在提升开发者工作效率，支持 macOS 和 Windows 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779633489740.webp)
------
- 项目地址：[plain-app](https://github.com/plainhub/plain-app)
- 项目说明：PlainApp 是一款基于 Android 的开源管理工具，能够通过网页浏览器安全访问手机文件、媒体、联系人等，旨在提供隐私保护的免费体验，支持 Android 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779633786702.webp)
------
- 项目地址：[EasyAIConfig](https://github.com/lmk1010/EasyAIConfig)
- 项目说明：一个基于 Node. Js 和 Tauri 开发的 AI 工具配置助手，能够一键安装和配置 Codex、ClaudeCode 等编程工具，旨在简化 AI 环境搭建，支持 macOS 和 Web 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779634595942.webp)
------
- 项目地址：[eve](https://github.com/nexmoe/eve)
- 项目说明：一个基于 Electron 开发的跨平台麦克风录音工具，能够实时转录音频并使用 VAD 技术，旨在长时间录音并自动分段保存，支持 Windows 和 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779634634132.webp)
