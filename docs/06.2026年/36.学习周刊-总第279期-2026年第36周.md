### 优秀项目

---
- 项目地址：[gos](https://github.com/opsre/gos)
- 项目说明：一个基于 Go 和 Vue 开发的发布治理平台，能够自由组合 CICD 流程，旨在通过发布单统一管理交付全链路，支持多种执行器如 Jenkins 和 ArgoCD。
  ![](https://t.eryajf.net/imgs/2026/05/1780214023422.webp)
------
- 项目地址：[CodexBar](https://github.com/steipete/CodexBar)
- 项目说明：一个基于 Swift 开发的 macOS 菜单栏应用，能够实时监控和显示数十种主流 AI 编码服务的使用限额与额度重置倒计时，旨在帮助开发者高效规划 AI 编码任务，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1780216167651.webp)
------
- 项目地址：[kaloscope](https://github.com/kaloscope/kaloscope)
- 项目说明：一款基于可视化工作流引擎开发的本地媒体库管理工具，能够通过节点化编辑器灵活对接各类资源站点与元数据源，旨在为用户构建高度可定制的媒体管理与自动化流程。
  ![](https://t.eryajf.net/imgs/2026/05/1780217580916.webp)
------
- 项目地址：[skyadb](https://github.com/sky22333/skyadb)
- 项目说明：一个基于 Kotlin 和 Jetpack Compose 开发的 Android ADB 客户端工具，能够通过无线调试管理手机、平板、电视和盒子，旨在提供便捷的设备管理体验，支持 Android 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1780218863020.webp)
------
- 项目地址：[dbx](https://github.com/t8y2/dbx)
- 项目说明：一个基于 Tauri 2 和 Vue 3 开发的轻量级跨平台数据库客户端，能够连接 40 多种数据库并集成 AI 助手，旨在提供高效、统一的数据库管理体验，支持桌面、Docker 和 Web 端使用。
  ![](https://t.eryajf.net/imgs/2026/05/1780219902316.webp)
------
- 项目地址：[dory](https://github.com/dorylab/dory)
- 项目说明：一个基于人工智能的 SQL 数据工作区，集成智能 SQL 助手、模式感知编辑和数据库聊天功能，旨在提升数据查询和管理效率，支持多种数据库。
  ![](https://t.eryajf.net/imgs/2026/06/1780494351084.webp)
------
- 项目地址：[conar](https://github.com/wannabespace/conar)
- 项目说明：一个基于 React 和 TypeScript 开发的 AI 驱动数据库管理工具，能够支持 PostgreSQL、MySQL、MSSQL 和 Clickhouse 等多种数据库，旨在简化 SQL 查询编写和优化，支持跨平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1780494409391.webp)
------
- 项目地址：[ore-code](https://github.com/233i/ore-code)
- 项目说明：一个基于 Tauri 和 TypeScript 开发的桌面编码代理工具，能够提供长上下文编码和结构化工具执行，旨在为开发者提供本地项目上下文和 DeepSeek 优先工作流支持，支持 macOS 和 Windows 平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1780533730414.webp)
