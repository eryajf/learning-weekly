### 优秀项目

---
- 项目地址：[tolaria](https://github.com/refactoringhq/tolaria)
- 项目说明：基于 Tauri 的 Markdown 知识库管理工具，开源离线设计，支持跨平台使用，适合知识整理。
  ![](https://t.eryajf.net/imgs/2026/06/1780623497775.webp)
------
- 项目地址：[hosts-manager-extension](https://github.com/ccpopy/hosts-manager-extension)
- 项目说明：一个基于 Chrome 扩展开发的 hosts 管理工具，能够通过分组管理映射规则并支持 socket 代理，旨在提供本地化、安全的主机配置解决方案。
  ![](https://t.eryajf.net/imgs/2026/06/1780666781860.webp)
------
- 项目地址：[shortcast](https://github.com/mutonby/shortcast)
- 项目说明：一个基于 Gemma 4 12 B 和 WhisperKit 开发的 macOS 原生应用，能够自动将长视频剪辑成短视频并添加字幕，旨在帮助用户快速生成 TikTok、Reels 和 YouTube Shorts 内容，支持全设备端处理，确保隐私安全。
  ![](https://github.com/mutonby/shortcast/raw/main/assets/demo.gif)
------
- 项目地址：[Fanny-MacOs-FanControl](https://github.com/ShahzaibAli02/Fanny-MacOs-FanControl)
- 项目说明：一个基于 SwiftUI 开发的 macOS 风扇控制工具，能够实时监控和调节风扇速度，旨在提供精准的温度控制和自动化规则，支持 Intel 和 Apple Silicon 平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1780673139111.webp)
------
- 项目地址：[gantry](https://github.com/getgantry/gantry)
- 项目说明：一个基于 SwiftUI 开发的 macOS 原生 Docker 管理应用，支持本地和 SSH 远程监控，内置 MCP 服务器和 App Intents。
  ![](https://t.eryajf.net/imgs/2026/06/1780673245397.webp)
------
- 项目地址：[StayAwake](https://github.com/TY-teo/StayAwake)
- 项目说明：一个基于 SwiftUI 开发的 macOS 菜单栏工具，能够防止系统休眠并支持合盖运行，旨在为 AI 编程代理如 Claude Code 提供稳定后台环境，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1780730484054.webp)
------
- 项目地址：[Adnify](https://github.com/ad-naan/Adnify)
- 项目说明：一个基于 AI 技术开发的代码编辑器，能够深度集成智能代理实现全流程自动化，旨在提供超越主流工具的流畅体验，支持多平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1780755797705.webp)
