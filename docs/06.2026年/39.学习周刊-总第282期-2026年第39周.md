### 优秀项目

---
- 项目地址：[Liftoff](https://github.com/firstfu/Liftoff)
- 项目说明：一个基于 Swift 开发的 macOS 26 启动台替代工具，能够还原经典 Launchpad 网格，支持实时窗口预览、智能分类与极速搜索，旨在提供高效、隐私安全的应用启动体验。
  ![](https://github.com/firstfu/Liftoff/raw/main/assets/hero.gif)
------
- 项目地址：[canary](https://github.com/wizenheimer/canary)
- 项目说明：一个基于 Playwright 和 QuickJS 沙箱开发的 QA 测试工具，能够为 Claude Code 等编码代理自动化 UI 测试，生成可重用脚本，支持屏幕录制、控制台日志和网络 HAR，旨在提升测试效率和可追溯性。
  ![](https://t.eryajf.net/imgs/2026/06/1781018748547.webp)
------
- 项目地址：[horseMD](https://github.com/BND-1/horseMD)
- 项目说明：一个基于 Electron 和 Milkdown 开发的免费 Markdown 编辑器，能够实现标签页和文件树管理，旨在提供类似 Typora 但更高效的工作流，支持 Windows 和 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/06/1781018895711.webp)
------
- 项目地址：[wayland](https://github.com/FerroxLabs/wayland)
- 项目说明：Wayland 是一个本地 AI 代理命令中心，集成多种 AI CLI，支持跨平台从单一界面执行复杂任务，旨在提升工作效率。
  ![](https://t.eryajf.net/imgs/2026/06/1781019090949.webp)
------
- 项目地址：[YanAI](https://github.com/huaiyuechusan/YanAI)
- 项目说明：一个基于 gpt-image-2 开发的美颜美图工具，能够提供在线画图和图片编辑功能，旨在实现自托管的图片创作与管理，支持多用户并发和 WebDAV 归档。
  ![](https://t.eryajf.net/imgs/2026/06/1781019129481.webp)
------
- 项目地址：[Git-Identity-Manager](https://github.com/phricardo/Git-Identity-Manager)
- 项目说明：一个基于 Tauri 2 开发的桌面应用，能够帮助开发者管理多个 Git 身份和 GitHub CLI 账户，旨在简化不同账户间的切换过程，支持 Windows 和 Linux 平台使用。
------
- 项目地址：[scratch](https://github.com/erictli/scratch)
- 项目说明：一个基于 Tauri 和 React 开发的极简 Markdown 笔记应用，支持离线使用和跨平台同步，旨在提供轻量高效的笔记体验。
  ![](https://t.eryajf.net/imgs/2026/06/1781085788392.webp)
------
- 项目地址：[synara](https://github.com/Emanuele-web04/synara)
- 项目说明：一个基于 TypeScript 开发的本地优先桌面应用，能够整合 Claude、Codex 等多种 AI 编码代理与终端、代码预览工具，旨在为开发者提供一体化的协作编码工作空间，支持并行多线程工作与本地数据存储。
  ![](https://t.eryajf.net/imgs/2026/06/1781141972771.webp)
