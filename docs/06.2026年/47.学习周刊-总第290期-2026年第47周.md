------

- 项目说明：一个基于 TypeScript 开发的开源 AI 助手，支持多设备协作、模型接入与工具扩展，旨在提升个人工作效率，兼容桌面和移动平台。

- 项目地址：[BokeBox](https://github.com/vastsa/BokeBox)
- 项目说明：一个基于 React 和 Fastify 的私有 AI 播客工具，能将视频文章转为音频节目，支持插件与 MCP，保障数据自主可控。
  ![](https://t.eryajf.net/imgs/2026/07/1784491977936.webp)
------
- 项目地址：[tura](https://github.com/Tura-AI/tura)
- 项目说明：一个本地开源编程智能体，通过宏命令和上下文管理减少模型轮次与令牌消耗，提升复杂开发任务效率。
  ![](https://github.com/Tura-AI/tura/raw/main/assets/screenshot/gui-ci-quality-demo.svg)
---------
- 项目地址：[kiri](https://github.com/libracoder/kiri)
- 项目说明：一个基于 Rust 开发的轻量级容器运行时，兼容 Docker 生态，支持 macOS、Windows 和 Linux，启动快速且资源占用低。
  ![](https://t.eryajf.net/imgs/2026/11/1794063654455.webp)

- 项目地址：[usage](https://github.com/aqua5230/usage/blob/main/README.zh-CN.md)
- 项目说明：一个本地日志驱动的配额监控工具，显示多模型用量，旨在主动管理成本，支持 macOS 和 Windows。
  ![](https://t.eryajf.net/imgs/2026/07/1784492189433.webp)
------
- 项目地址：[AgentSwitchboard](https://github.com/xzulab/AgentSwitchboard/blob/main/README.zh-CN.md)
- 项目说明：一个基于静态网页的 AI 编程工具配置档案管理器，能够本地切换模型、网关与认证配置，旨在安全简化多工具配置管理。
  ![](https://t.eryajf.net/imgs/2026/07/1784492492434.webp)
------
- 项目地址：[file-viewer](https://github.com/flyfish-dev/file-viewer)
