### 优秀项目

---
- 项目地址：[http-stat-rs](https://github.com/vicanso/http-stat-rs)
- 项目说明：一个基于纯 Rust 开发的 HTTP 统计工具，能够可视化请求生命周期，支持 HTTP/1.1、HTTP/2 和 HTTP/3 协议，旨在提供详细的网络诊断，适用于脚本和 CI/CD 集成。
  ![](https://t.eryajf.net/imgs/2026/05/1779635819100.webp)
------
- 项目地址：[lite-edit](https://github.com/arietan/lite-edit)
- 项目说明：一个基于 Swift 和 AppKit 开发的轻量级 macOS 代码编辑器，能够快速打开和编辑代码文件，支持语法高亮、多标签页和文件浏览，旨在提供极速、原生的代码编辑体验，支持 macOS 13+ 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779635930155.webp)
------
- 项目地址：[nezha](https://github.com/hanshuaikang/nezha)
- 项目说明：一个基于 Tauri 和 React 开发的代理优先 IDE 工具，能够并行运行多个 AI 编码代理，旨在简化多项目任务管理，支持跨平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779635966796.gif)
------
- 项目地址：[superhq](https://github.com/superhq-ai/superhq)
- 项目说明：一个基于 Rust 和 GPUI 开发的沙盒化 AI 智能体编排平台，能够运行多个 AI 编码智能体在隔离环境中，提供完整终端访问，旨在安全管理和编排不同 AI 工具，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636056790.webp)
------
- 项目地址：[holaOS](https://github.com/holaboss-ai/holaOS)
- 项目说明：一个基于 AI 开发的工作流自动化工具，能够将重复工作转化为智能工作流，旨在提升效率，支持多平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636107064.webp)
------
- 项目地址：[SuperCmd](https://github.com/SuperCmdLabs/SuperCmd)
- 项目说明：一个基于 Electron 和 React 开发的 macOS 启动器，集成了 Raycast 兼容扩展、语音工作流和 AI 功能，旨在提升生产力和效率，支持 macOS 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636141449.webp)
------
- 项目地址：[llm_wiki](https://github.com/nashsu/llm_wiki)
- 项目说明：一个基于 Tauri 和 React 开发的跨平台桌面应用，能够利用 LLM 自动将文档转化为组织化的知识库，旨在通过增量构建和维护持久维基来提升知识管理效率，支持 macOS、Windows 和 Linux 平台使用。
  ![](https://t.eryajf.net/imgs/2026/05/1779636349271.webp)
