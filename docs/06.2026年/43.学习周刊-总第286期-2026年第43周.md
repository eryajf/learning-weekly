- 项目说明：一个利用 ChatGPT 订阅生成图片的零依赖 Python CLI 工具，无需 API 密钥，通过 web 或 codex 后端驱动，可作为 AI 代理技能，轻松集成到命令行工作流中。

- 项目地址：[html-tools](https://github.com/chicogong/html-tools)
- 项目说明：这是一个拥有 1086+工具的纯前端在线工具集，采用单文件架构无需构建，支持离线使用，所有数据处理均在本地完成，注重隐私保护。
  ![](https://t.eryajf.net/imgs/2026/06/1781837643477.webp)
------
- 项目地址：[Arc](https://github.com/lyon916/Arc)
- 项目说明：一个基于 React 和 TypeScript 开发的浏览器端 API 调试工具，无需安装即可在线使用，内置 CORS 代理，支持环境变量、集合管理和代码生成，旨在提供本地优先的轻量级 Postman 替代方案。
  ![](https://t.eryajf.net/imgs/2026/06/1781838002402.webp)
------
- 项目地址：[Cowart](https://github.com/zhongerxin/cowart#)
- 项目说明：一个基于 tldraw 的 Codex 本地无限画布插件，用于 AI 辅助构思、标注与图片生成，支持本地持久化与 MCP 工具集成。
  ![](https://t.eryajf.net/imgs/2026/06/1782134401381.webp)
------
- 项目地址：[ORG2](https://github.com/yorgai/ORG2)
- 项目说明：一个基于 Rust 和 Tauri 构建的开源代理 IDE，提供可审查的 AI 编码体验，支持 10+ CLI 工具，旨在实现本地优先的人机协作控制。
  ![](https://t.eryajf.net/imgs/2026/06/1782134516126.webp)
------
- 项目地址：[OpenViking](https://github.com/volcengine/OpenViking/blob/main/README_CN.md)
- 项目说明：一个为 AI 智能体设计的开源上下文数据库，通过文件系统范式统一管理记忆、资源与技能，支持分层加载与目录检索，降低 Token 消耗，提升开发效率。
------
- 项目地址：[casos](https://github.com/casosorg/casos)
- 项目说明：一个基于 Kubernetes 构建的云操作系统，内置完整控制平面，无需外部集群即可通过 Web 界面管理节点、Pod 和服务，支持认证和多平台部署。
  ![](https://t.eryajf.net/imgs/2026/06/1782266724788.webp)

- 项目说明：一款基于 Rust 与 Canvas 开发的轻量级屏幕标注工具，能够随时随地用快捷键在桌面上绘画、标注，旨在提供即开即用、极低资源占用的标注体验，支持 Windows 和 macOS 平台。
